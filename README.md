# OSCE 考站計時器

給 OSCE 考官在考場用手機操作的倒數計時器，單一 HTML 頁面，不需安裝。

**線上使用：** https://jessietsaicmu.github.io/osce-timer/

## 功能
- 預設每站 8 分鐘倒數（可選 5–12 分鐘），大字圓環顯示
- 剩 1 分鐘：轉黃、心跳提醒、響 2 聲並震動
- 時間到：轉紅、響長鈴，之後顯示超時秒數
- 點圓環開始／暫停；長按 1 秒重設；時間到可按「下一輪」，學員代號自動往下（學員A → 學員B）
- 計時中盡量保持螢幕常亮

## 使用提醒
- 手機請關閉靜音、調高音量，考前先按「試聽鈴聲」一次（手機瀏覽器需先點擊才能出聲）。
- 學員欄位請只填代號，勿輸入真實姓名、病歷號或任何可辨識個人的資料。
- 頁面不儲存、不上傳任何資料；鈴聲由瀏覽器即時合成，不含外部音檔或 AI 模型。
